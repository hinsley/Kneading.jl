Kneading.jl

Kneading.jl provides symbolic-dynamics tools for one-dimensional maps. Its current scope includes kneading data, finite kneading determinants, certified finite-surrogate entropy estimates, parameter-plane scans, and kneading diagram contours.

The package does not currently support weighted kneading theory or generalized topological pressures.

Kneading.Kneading — Module

Symbolic-dynamics tools for one-dimensional maps.

Use Kneading.OneDimensionalMaps for interval-map kneading data and entropy estimates. Use Kneading.Diagrams for parameter-plane scans and kneading-diagram contours.

source

Installation

Kneading.jl is currently installed directly from GitHub:

import Pkg
Pkg.add(url = "https://github.com/hinsley/Kneading.jl")

Package structure

The package has two public namespaces:

  • Kneading.OneDimensionalMaps contains interval maps, kneading algebra, and entropy estimates.
  • Kneading.Diagrams contains parameter-plane scans, contour geometry, and optional CairoMakie plotting methods.
Kneading.OneDimensionalMaps — Module

Interval maps, finite kneading data, kneading algebra, and finite-surrogate entropy estimates.
